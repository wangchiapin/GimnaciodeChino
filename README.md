# 中文健身房（Gimnacio de Chino）

> WhatsApp 中文練習群組的管理工具：記錄每週語音練習、黃牌／紅牌、成員狀態。只給老師自己用，不是學生端。

- **網址：** https://wangchiapin.github.io/GimnaciodeChino/
- **Firebase 專案：** gimnacio-de-chino
- **登入方式：** 匿名登入
- **狀態：** 使用中
- **備註：** 資料在 `whatsappGroup` 集合（文件 `weeks` 等，每份資料存在 `data` 欄位）。與 `note`（隨手貼）、`onedayoneword`（語料庫管理）共用此 Firebase 專案；改 Firestore 規則前要一併確認這三個。

給 Claude：改這個工具前先讀這份。Ben 的規則：先討論、測好、問過才推（他說「推」才推）；用白話繁體中文說明。畫面風格是純**無印風**，不要用品牌色（磚紅、玉綠、金色）。

## 畫面（單一 `index.html`，Vue 3 ＋ Firebase）

1. **總表（主頁）**：上方有群組分頁和「全體」分頁；表格是活躍成員 × 週次。姓名欄凍結，最新一週整欄標示。
2. **成員資訊頁**：可改姓名、自我介紹、入群／退群時間、退群原因、重新加入資格；顯示出席、黃牌、紅牌統計與每週紀錄明細。
3. **成員資訊總覽**：活躍與已退群成員的清單（群組、國籍、年齡、入群時間、累計語音則數、參與週數、出席率、黃牌、紅牌）。
4. **週次練習表**：新增、修改、刪除練習週次，看每週有誰參加。
5. **群組管理**：新增、修改、刪除群組並選擇成員。每位成員最多屬於一個群組；週次是所有群組共用的。

手機版有**底部導覽列**、「＋」新增面板（新增成員／週次）；表格預設只顯示最近兩週，可切換顯示全部。

## 記錄規則

- 點格子上半部：讚數依序切換 👍 → 👍👍 → 👍👍👍 → 空白。
- 點格子下方的小方塊：黃牌 🟨 → 紅牌 🟥 → 空白，**和讚數各自獨立**，保留「發了幾則但沒達標」的完整歷史。
- 點到紅牌會觸發退群確認。黃牌就算之後被拿掉，紀錄仍保留並持續累積；**累積 5 張黃牌自動視同紅牌**，一樣觸發退群流程。
- 誤點的黃牌可以排除。新增成員時，如果目前在某個群組分頁，就自動加入那個群組；活躍名單依群組順序排列，沒有群組的排最後；重名會提醒。

## 進入頁面的提示視窗

每次進入頁面，會跳出懸浮視窗，顯示兩個群組建立多久了。群組的建立日期寫在 `index.html` 的 `GROUP_ANCHORS`（群組 1：2026-02-27、群組 2：2026-09-09，名稱還沒正式決定），要改日期或名稱改這裡。

## 資料安全

- 資料寫入 Firebase 時，如果雲端資料沒讀到（載入失敗），整個畫面會鎖住並提示，避免舊資料覆蓋雲端。存檔採延遲合併。
- 前端沒有帳號密碼，真正的防線是 **Firestore 安全規則**，請確認主控台的規則不是對所有人開放寫入。

## 共用此 Firebase 專案的其他工具（改規則前先看）

規則只存在 Firebase 主控台，**不在任何 repo 裡**。這個專案同時被三個工具使用，規則要同時放行下面這些路徑，漏掉哪個，那個工具就會讀寫失敗：

| 工具 | 讀寫的 Firestore 路徑 | 登入方式 |
|---|---|---|
| 本工具（GimnaciodeChino） | `whatsappGroup/{文件}`（`weeks`、`members` 等） | 匿名登入 |
| `note`（隨手貼） | `users/{uid}/clips/{筆記}`（含設定用的 `__settings__`） | Google 登入 |
| `onedayoneword`（語料庫管理） | `vocabulary/main`、`sentences/main` | 沒有登入 |

注意 `onedayoneword` 完全不登入，所以那兩份文件的規則如果要求登入，它就會壞掉；`note` 則一定要登入後、只能存取自己 uid 底下的資料。目前主控台上的規則實際長怎樣，這邊沒有紀錄，要進主控台確認。
